# 🚀 DingSao Launch Checklist

Quick reference for executing the marketing launch.

## Pre-Launch (Today)

- [ ] Review content files in `marketing/` folder
- [ ] Verify `.env` credentials are correct
- [ ] Register dev.to account via GitHub OAuth
- [ ] Register Hacker News account
- [ ] Test demo site can handle traffic load

## Karma Building (Days 1-7)

- [ ] Make 5-10 quality comments on HN per day
- [ ] Focus on: AI tools, indie hacking, developer productivity topics
- [ ] Target: 10+ karma before Show HN post
- [ ] No promotional language, be genuinely helpful

## Launch Day (Day 8 - Tuesday/Wednesday)

### Morning (9-11 AM EST)

- [ ] **9:00 AM:** Publish dev.to article
  - Copy from `marketing/dev-to-post.md`
  - Upload cover image
  - Add tags: webdev, opensource, ai, productivity
  - Publish immediately

- [ ] **11:00 AM:** Post Show HN
  - Title: "Show HN: DingSao – AI-powered web monitoring that tells you what changed"
  - URL: https://github.com/pxivory-max/dingsao
  - Text: Copy from `marketing/hn-post.md` (optional)

### First 2 Hours (CRITICAL)

- [ ] Monitor HN comments every 5-10 minutes
- [ ] Monitor dev.to reactions and comments
- [ ] Respond to questions quickly and honestly
- [ ] Be present and engaged

### Rest of Day 8

- [ ] Continue monitoring both platforms
- [ ] Track referral traffic to demo site
- [ ] Note all bug reports and feature requests
- [ ] Thank commenters and contributors

## Post-Launch (Days 9-14)

- [ ] Respond to all new comments daily
- [ ] Convert feedback to GitHub issues
- [ ] Update README if needed based on feedback
- [ ] Cross-post dev.to link to Twitter/LinkedIn
- [ ] Share on Reddit (r/SideProject, r/webdev) if appropriate

## Success Criteria

**Minimum Success:**
- 50+ HN points (front page appearance)
- 50+ dev.to reactions
- 10+ GitHub stars
- 5+ meaningful feature requests

**Excellent Success:**
- 100+ HN points (trending)
- 100+ dev.to reactions
- 50+ GitHub stars
- Demo site gets real users
